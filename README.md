# 道路施工管制时段采录（Flask）

公交信息员将道路施工公告中的管制时段录入乘客信息系统的网页工具：上传公告
HTML，选择表格与四列映射，处理跨行合并的开始/结束时间，按行导出 CSV。
另提供“交接下载”：交付的 CSV 与逐格来源一并存入 SQLite，收到退回单后可凭
批号、数据行号、字段名回查公告原格。

## 功能

- 上传公告 `.html/.htm`（UTF-8/GBK 自动识别），或一键载入内置的带合并格公告样例。
- 一张公告含多张表时可下拉选择；可手动指定**路段、方向、开始、结束**四列，
  表头关键词可自动识别，原表预览高亮被选列与合并覆盖格。
- 开始、结束两列的跨行合并格会被展开：覆盖格与原格共用同一时间。
  - 直接编辑共用时间框 = 改原格，只更新仍共用该时间（未覆盖）的行；
  - “单独覆盖此行”可给该行设置自己的起止时间，其余行不受影响；
  - “撤销覆盖”后该行重新取对应原格的最新值。
- 时间含日期和时分，兼容 `2026-11-15 22:00`、`2026/11/15 22:00`、
  `2026年11月15日22时00分` 等写法。
- 每行起止时间可分别覆盖；无法解析或**结束早于开始**的行标红，
  前端与后端双重校验，存在错误行时阻止导出与交接。

### 普通导出

- 按行导出 CSV（UTF-8 BOM，Excel 直接打开）：`路段,方向,开始,结束`。
- 仍是原来的四列与行序，首条数据为第 1 行。

### 交接下载

- 点击「交接下载」时，按**当时页面上的采录稿取值和来源**生成 CSV；
  校验沿用普通导出的同一套规则（后端独立复算时间与先后顺序）。
- 文件名带唯一批号：`traffic_control_<批号>.csv`，批号形如
  `TC-20261113-020416-A29369`。
- 先把实际交付的 CSV 字节和每个数据格（4 列 × 每行）的来源写入 SQLite，
  **事务提交成功后**才返回下载地址，前端随后触发下载；存档失败不提供下载。
- 每个格记录：字段、实际交付值、未编辑原文、原格行列、是否合并覆盖格、
  实际原格 ID、取值来源、数据行号与表内行号。

### 交接回查

- 网页「交接回查」输入批号、数据行号（首条数据为第 1 行）、字段名（可留空），
  显示公告文件名、表号、原格行列、未编辑原文、实际交付值与取值来源。
- 合并格（被 `rowspan/colspan` 覆盖的位置）显示“合并格覆盖，指向原格”，
  行列指向真正的原格。
- 时间字段注明来源：
  - `原值`：直接取公告原格未编辑的原文；
  - `共用改值`：原格被编辑后的共用值，本行未单独覆盖；
  - `单行覆盖`：本行单独设置的值。
  路段/方向同样标注 `原值` 或 `采录时编辑`，便于判断“原文有误”还是“采录改错”。
- 批号存档在 SQLite 中，换表、重新导入或服务重启后仍可回查，
  并可用存档中的原始字节按批号重下原文件（响应头带 `X-Batch-No` 与文件 SHA-256）。

## 启动方式（Docker Compose）

```bash
docker compose up --build
```

浏览器打开 <http://localhost:5000>：

1. 点击「载入带合并格的公告样例」；
2. 修改共用时间或单独覆盖某行后，点击「交接下载」，记下批号；
3. 在「交接回查」输入批号、行号（如 `2`）和字段（如 `开始`），
   即可看到原格行列、原文、实际交付值与来源。

批号数据库存放在 Compose 命名卷 `handover-data`（容器内 `/data/handovers.db`），
`docker compose down` 后重新 `up` 仍可回查；`down -v` 才会清空存档。

## 本地开发（无 Docker 时）

```bash
pip install -r app/requirements.txt
python app/app.py        # http://localhost:5000
```

本地默认存档在 `app/data/handovers.db`，可用环境变量 `HANDOVER_DB` 覆盖路径。

## 目录结构

```

```

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/export` | 普通导出（原有行为） |
| POST | `/api/handover` | 校验、存档并返回批号与下载地址 |
| GET | `/api/handover/<批号>` | 回查；可选 `?row=1&field=start` |
| GET | `/api/handover/<批号>/download` | 下载该批实际交付的原始 CSV |

字段名可用 `road/direction/start/end` 或 `路段/方向/开始/结束`。

## 说明

- 合并格模型：每个覆盖格携带原格 `id`；前端以原格 `id` 聚合共用行，
  编辑原格只改共用文本，已覆盖行保留私有值。
- 服务端 `/api/export` 与 `/api/handover` 独立复算全部时间与先后顺序，
  即使绕过页面也无法导出或交接错误数据。
- 交接存档只信任服务端复算出的交付值；若来源标为“原值”但交付值与原格原文
  不一致，交接会被拒绝，避免留下错误的来源记录。
